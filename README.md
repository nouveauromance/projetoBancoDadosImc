# Projeto Banco de Dados IMC

- Aplicativo mobile desenvolvido como atividade da disciplina de Programação para Dispositivos Móveis.

## Sobre o projeto

- O Projeto Banco de Dados IMC é um aplicativo mobile que realiza cadastro, login e cálculo do IMC do usuário, armazenando as informações no banco de dados SQlite.

## Escopo

- O aplicativo possui a seguinte funcionalidade:

  - Telas de cadastro e login:
    - Usuário realiza seu cadstro e login, salvando todas as informações no banco.
  - Cálculo do IMC:
    - Usuário insere informações solicitadas e realiza o cálculo.

## Instalação

- Instale o projeto com npm:

```bash
  npm install projetoBancoDadosImc
  cd projetoBancoDadosImc
  npm start
```
